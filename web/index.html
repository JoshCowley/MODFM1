FM1 Rack 1.1

A sound-design firmware for the M-VAVE FM-1: open-source eurorack modules in swappable slots, a 12-row mod matrix and four performance macros. This is the browser build, running the original module code.

Start in a minute

  1. Tap Switch on, then play the keys. Tap lower on a key to play louder, or use Z–/ and Q–O on a computer (- = for octave).
  2. Turn PRESETS to step through the 12 factory patches. Knobs 1–4 on HOME are the macros.
  3. Press a slot button (EDIT, ENV twice for the shaper, LFO, FX) to see that module move. Turn ALGORITHM there to swap the module, then press the button again to load it.

Handy moves

  • Hold HOME (or Shift-click it) and turn any knob to give it to a macro.
  • REC records keys and knob moves into a loop of 1, 2, 4 or 8 bars.
  • SCL turns each key into a chord in your key and scale, with scale lock on its second page. PLAY holds notes.
  • SEQ is a 16-step sequencer: play keys to fill steps, Space starts it. Hold SEQ and turn any knob to lock a value to a step.
  • SAVE names a patch into one of 16 user slots, kept in this browser.
  • A MIDI keyboard works where the browser allows it: notes, CC 1 and 21–24 to the macros, sustain, clock.

What's inside

  • Plaits, Braids, Elements, Rings, Warps, Clouds, Peaks, Tides 2, Marbles and Grids, from Émilie Gillet's original Mutable Instruments code (MIT; Grids GPL-3), compiled to WebAssembly. Not affiliated with Mutable Instruments.
  • FILTER, DELAY, REVERB and CHORUS stand in for the Felucca firmware's effects.
  • Not yet built for the FM-1 hardware. CPU and RAM figures are estimates.
